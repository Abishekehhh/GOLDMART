## ⚡ Super Quick Start

```bash
# 1. Install Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android

# 2. Initialize
npx cap init
# App name: Goldmart
# App ID: com.goldmart.app
# Web dir: dist

# 3. Build and add Android
npm run build
npx cap add android
npx cap sync

# 4. Open in Android Studio
npx cap open android

# 5. Build APK/AAB in Android Studio
# 6. Upload to Play Store
```
