# 📋 Google Play Store Submission Checklist

Complete checklist for publishing Goldmart app on Google Play Store.

---

## ✅ Pre-Submission Requirements

### 1. Developer Account
- [ ] Created Google Play Developer account
- [ ] Paid $25 one-time registration fee
- [ ] Completed account verification
- [ ] Added payment method (for paid apps, if applicable)

### 2. App Build
- [ ] App tested on multiple Android devices
- [ ] Release AAB built and signed
- [ ] Version code incremented (start with 1)
- [ ] Version name set (e.g., "1.0.0")
- [ ] App doesn't crash on launch
- [ ] All features work correctly

### 3. App Assets

#### Icons:
- [ ] App icon: 512x512 PNG (no transparency)
- [ ] Feature graphic: 1024x500 PNG
- [ ] All Android icon sizes generated (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)

#### Screenshots:
- [ ] Phone screenshots: Minimum 2, Maximum 8
  - Minimum height: 320px
  - Maximum height: 3840px
  - Format: PNG or JPG
  - Aspect ratio: 16:9 or 9:16
- [ ] Tablet screenshots: Optional but recommended
- [ ] Screenshots show key features:
  - [ ] Homepage
  - [ ] Jewellery listing
  - [ ] Product details
  - [ ] Shop listing
  - [ ] Search functionality

---

## 📝 Store Listing Information

### 4. App Details
- [ ] **App name**: Goldmart (or your preferred name)
- [ ] **Short description**: 80 characters max
  - Example: "Your trusted marketplace for authentic gold jewellery"
- [ ] **Full description**: Up to 4000 characters
  - Include:
    - What your app does
    - Key features
    - Benefits for users
    - Any special offers
- [ ] **App category**: Shopping / Lifestyle
- [ ] **Default language**: English

### 5. Graphics & Media
- [ ] App icon uploaded (512x512)
- [ ] Feature graphic uploaded (1024x500)
- [ ] Phone screenshots uploaded (2-8 images)
- [ ] Tablet screenshots (optional)
- [ ] Promo video (optional but recommended)

### 6. Content Rating
- [ ] Completed content rating questionnaire
- [ ] Received rating certificate
- [ ] Rating is appropriate for your app

### 7. Privacy & Security

#### Privacy Policy:
- [ ] Privacy policy URL created and accessible
- [ ] Privacy policy includes:
  - [ ] Data collection practices
  - [ ] How data is used
  - [ ] Data sharing (if any)
  - [ ] User rights
  - [ ] Contact information
- [ ] Privacy policy URL added to Play Console

#### Data Safety:
- [ ] Completed Data Safety section
- [ ] Declared data collection (if any)
- [ ] Declared data sharing (if any)
- [ ] Security practices declared

### 8. Target Audience
- [ ] Age group selected
- [ ] Content guidelines reviewed
- [ ] Appropriate for selected audience

### 9. Pricing & Distribution
- [ ] App set as Free or Paid
- [ ] Countries selected (or worldwide)
- [ ] Content guidelines accepted
- [ ] Export compliance (if applicable)

---

## 🔍 App Quality Checklist

### 10. Functionality
- [ ] App launches without crashes
- [ ] All navigation works
- [ ] All buttons/links functional
- [ ] Images load correctly
- [ ] Forms submit properly
- [ ] Search functionality works
- [ ] No broken links

### 11. Performance
- [ ] App loads quickly
- [ ] Smooth scrolling
- [ ] No lag or freezing
- [ ] Efficient memory usage
- [ ] Battery usage reasonable

### 12. User Experience
- [ ] Intuitive navigation
- [ ] Clear call-to-actions
- [ ] Readable text (proper font sizes)
- [ ] Proper spacing and layout
- [ ] Works in portrait and landscape (if supported)
- [ ] Responsive design

### 13. Compatibility
- [ ] Tested on Android 8.0+ (API level 26+)
- [ ] Tested on different screen sizes
- [ ] Tested on different manufacturers (Samsung, Xiaomi, etc.)
- [ ] Works on tablets (if targeting tablets)

---

## 📱 Technical Requirements

### 14. App Signing
- [ ] Release AAB signed with keystore
- [ ] Keystore file backed up securely
- [ ] Keystore password saved securely
- [ ] App signing key enrolled (Google Play App Signing)

### 15. Permissions
- [ ] Only necessary permissions requested
- [ ] Permission descriptions provided
- [ ] Runtime permissions handled correctly (Android 6.0+)

### 16. Network Security
- [ ] HTTPS used for all network requests
- [ ] No cleartext traffic (unless necessary)
- [ ] SSL certificates valid

---

## 📄 Required Documents

### 17. Legal & Compliance
- [ ] Privacy policy URL (required)
- [ ] Terms of service (recommended)
- [ ] Contact information provided
- [ ] Content complies with Play Store policies
- [ ] No copyright violations
- [ ] No trademark violations

### 18. Content Guidelines
- [ ] No prohibited content
- [ ] No misleading information
- [ ] Accurate app description
- [ ] Screenshots match actual app
- [ ] No spam or deceptive practices

## 🚀 Submission Process

### 19. Pre-Launch Checklist
- [ ] All sections completed (green checkmarks)
- [ ] App tested thoroughly
- [ ] All assets uploaded
- [ ] Store listing complete
- [ ] Content rating obtained
- [ ] Privacy policy accessible

### 20. Submit for Review
- [ ] Click "Submit for review"
- [ ] Review submission summary
- [ ] Confirm all information is correct
- [ ] Submit

### 21. Post-Submission
- [ ] Monitor review status
- [ ] Respond to any feedback quickly
- [ ] Prepare for launch
- [ ] Plan marketing strategy

---

## 📊 Review Timeline

- **Initial Review**: 1-3 days
- **If Issues Found**: Additional 1-4 days after fixes
- **Total**: Usually 1-7 days

**Status Updates:**
- In review
- Changes requested
- Rejected (with reasons)
- Published ✅
